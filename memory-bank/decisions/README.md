# ADR — записи архитектурных решений

Здесь фиксируются решения, а не инструкции: «почему сделано так» для будущего читателя,
который увидит код и удивится. Как что-то делать — в `runbooks/`, чему научились — в `lessons/`,
что сломано — в `known-issues/`.

## Конвенция

- Имя файла: `ADR-NNNN-kebab-slug.md`, номер четырёхзначный. Другие варианты
  (`ADR0001_…`, `ADR__0001__…`) устарели — не заводить.
- Номер — **идентификатор, а не хронология**: он неизменен, пока ADR живёт в этом каталоге.
  Порядок номеров не совпадает с порядком дат.
- Новый номер = максимальный существующий + 1.
- Номерное пространство `ADR-NNNN` принадлежит **только этому каталогу**. Запись, снятая с серии,
  уезжает в `../_archive/decisions/` и **теряет номер** (файл переименовывается в `slug.md`,
  внутри остаётся пометка `archived_from`) — так один номер всегда указывает ровно на один документ.
- Frontmatter:
  ```yaml
  ---
  type: adr
  number: "0011"
  title: Короткое название решения
  date: 2026-07-30
  status: accepted        # proposed | accepted | deprecated | superseded by ADR-NNNN
  tags: [architecture, ...]
  ---
  ```
- Первая строка тела — `# ADR-NNNN: <title>`.
- Язык — русский (кроме уже написанных по-английски: их не переводим).

## Объём

**Короткий ADR — нормальный ADR.** Одного абзаца «контекст → что решили → почему» достаточно;
разделы `Alternatives` / `Consequences` добавляй только когда отклонённые варианты или
неочевидные последствия реально стоит помнить. Старые записи здесь на 200+ строк — это
исторический перекос, а не образец.

## Когда ADR нужен

Только если верны **все три** условия:

1. **Трудно обратить** — сменить решение потом дорого (миграции `migrations/NNNN_*`,
   маппинг проводок ГК с последующим репостом через `u508`, структура слоёв).
2. **Неочевидно без контекста** — читатель кода спросит «почему так?».
3. **Был реальный размен** — существовали настоящие альтернативы, выбрали одну по причинам.

Легко обратимо → не пиши, просто обратишь. Нет альтернатив → нечего фиксировать.
Конвенция кодирования → `code-standards/`, а не ADR.
