# UI Check

Проверка диффа фронтенда против `memory-bank/architecture/ui-standard.md`.

**Язык отчёта — русский.**

## Разделение труда: что проверяет не этот скилл

Половину правил считает генератор — **не дублируй его работу вручную**:

```powershell
powershell -File tools/gen_ui_registry.ps1
```

Он пишет `UI_REGISTRY.md` и закрывает **UI-010, UI-011, UI-020…UI-023** (новые
блок-руты вне allowlist, блоки в нескольких файлах, хардкод, сломанные и
дрейфующие токены). Твоя часть — то, что требует чтения разметки и суждения.

## Область: только диффа

Проверяй **изменённые файлы**, а не весь репозиторий. Это не оптимизация, а
условие работоспособности: в коде ~4 400 инлайн-стилей и 402 неиспользуемых
класса, и полный проход утопит любой полезный сигнал.

```powershell
git diff --name-only HEAD           # рабочие изменения
git diff --name-only main...HEAD    # ветка целиком
```

Фильтруй до `crates/frontend/**` (`.rs`, `.css`, `index.html`).
Если пользователь назвал файлы или диапазон коммитов — бери их.

## Никаких сборок

Только `Grep` / `Read` / `Glob` и `git diff`. **Не запускай `cargo` / `trunk`** —
компиляция здесь самая дорогая операция (wasm-check ≈ 1 мин), а для проверки
разметки и CSS она не нужна. Исключение — генератор выше, он не компилирует.

## Правила

Полные формулировки — в `ui-standard.md`. Паттерны поиска и легальные
исключения — [RULES.md](./RULES.md). Проверяй только те правила, которых
изменённые файлы реально касаются.

## Формат отчёта

Группируй по файлам, каждое нарушение — с ID правила и ссылкой `файл:строка`:

```
crates/frontend/src/domain/a041_x/ui/list/mod.rs
  UI-001  корень страницы — <div class="page">, а не <PageFrame>        :42
  UI-030  инлайн style="padding: 8px" — статика, должно быть классом    :117

crates/frontend/static/pages/a041_x.css
  UI-050  новое семейство `.a041-table` — есть .table__data (UI-053)    :12
```

Если чисто — так и скажи одной строкой, без списка проверенного.

**Не чини молча.** Скилл диагностирует; правки — отдельным шагом по просьбе.

## Здравый смысл

- Правило, помеченное в `ui-standard.md` как **[авто]**, уже посчитал
  генератор — не пересчитывай, а сошлись на `UI_REGISTRY.md`.
- Категории `custom` и `legacy` (`page_standard.rs`) — осознанные исключения:
  `custom` не проверяется на структуру вовсе, `legacy` даёт только напоминание,
  а не нарушение.
- Нашёл нарушение в строке, которую дифф не трогал, — упомяни отдельным
  блоком «рядом, вне диффа», не смешивая с претензиями к самим изменениям.
- Правило без ID — это мнение. Если считаешь, что чего-то не хватает в
  стандарте, предложи новое правило явно, а не выдавай его за существующее.
