# Правила: паттерны и исключения

Для каждого правила — как искать и что НЕ считать нарушением.
Нормативные формулировки — `memory-bank/architecture/ui-standard.md`.

Правила **[авто]** считает `tools/gen_ui_registry.ps1`; здесь они перечислены,
чтобы понимать, что уже покрыто, и не проверять их руками.

---

## UI-001 — PageFrame и id `{entity}--{category}`

Компонент страницы (то, что регистрируется в `layout/tabs/registry.rs`) должен
начинаться с `<PageFrame page_id="..." category=PAGE_CAT_*>`.

**Ищи:** в новых/изменённых компонентах страниц — корневой `<div class="page"`
с руками написанным `id=` / `data-page-category=`.

**Не нарушение:** вложенные компоненты (вкладки, виджеты, модалки) — у них
корня страницы нет вообще. Правило только про то, что рендерится в таб.

---

## UI-002 — `page__header` и `page__content` — прямые дети

**Ищи:** внутри `PageFrame` — обёртку между корнем и этими блоками.

**Не нарушение:** категории `custom` (свободная вёрстка) и страницы, где между
ними стоит `page__tabs` — это как раз требование UI-003.

---

## UI-003 — TabBar

Должно быть: `<div class="page__tabs">` + `<button class="page__tab">`,
расположенный **между** `page__header` и `page__content`.

**Нарушение:** Thaw `<Button>` в роли вкладки; `<Flex>` как контейнер вкладок;
`page__tabs` внутри `page__content`.

Исторический контекст: до 2026-02 стандарт требовал Thaw-вариант, он остался в
`edit-details-mvvm-standard.md` и помечен там устаревшим. Старый код на Thaw —
долг, а не ошибка автора; в отчёте отмечай, только если файл менялся.

---

## UI-010 / UI-011 — allowlist и один владелец блока   **[авто]**

Считает генератор. Смотри в `UI_REGISTRY.md`:
- «Block roots» → статус `**unregistered**`;
- «Blocks defined in more than one file».

Одобрить новый блок = строка в `crates/frontend/static/ui-registry.allow.json`
с осмысленным `reason` (не `bootstrap` — он зарезервирован под первичный импорт).

---

## UI-012 — BEM-грамматика

`block__element--modifier`, максимум 2 уровня.

**Нарушение:** `block__el__sub` (три уровня); модификатор без базового класса
(`class="card--wide"` без `card`); camelCase (`.tableCell`).

**Не нарушение:** составное имя блока через дефис (`.a007-link-card`) — это один
блок, а не вложенность.

---

## UI-013 — запрещённые имена

```
\.(checkbox-cell|tableCell|cell|active|status|value|name)\b
```
в определениях CSS. Неспецифичные глобальные имена ломают изоляцию страниц.

**Не нарушение:** те же слова как **элемент** блока (`.plugin-host__status`) —
запрещены только как самостоятельные блок-руты.

---

## UI-014 — per-page CSS scoped под корнем страницы

Все правила в `static/pages/<page>.css` должны начинаться с корневого класса или
id страницы.

**Ищи:** в page-файле — селектор, начинающийся с глобального блока
(`.modal`, `.page__content`, `.table`, `.form__input`, `.badge`).

**Не нарушение:** `#<page_id> .table__head { ... }` — глобальный блок, но
ограниченный страницей (так сделан осознанный отказ от sticky в
`quality_check_details.css`, там есть объясняющий комментарий).

---

## UI-020…UI-023 — токены   **[авто]**

Считает генератор:
- хардкод hex/px → «Hardcode by file»;
- сломанные ссылки → «Undefined ... NO fallback (broken)» (должно быть 0);
- дремлющие → «Undefined but always carries a fallback»;
- дрейф тем → «Theme drift» (должно быть 0).

Три категории **не бьются** и это нормально: `--thaw-*`/camelCase (приходят из
Thaw в рантайме) и переменные, которые Rust ставит на элемент (`style:--x=..`).

---

## UI-030 — инлайн-стили

**Нарушение:** статика — `style="padding: 8px"`, `attr:style="width: 100%"`.

**Не нарушение** (значение вычисляется в рантайме):
- ширина колонки из сигнала/localStorage;
- `style:padding-left=` по глубине дерева;
- `--nav-i`, `--drill-cols`, `--from-x`, `--from-y`, `--mp-color` — переменные,
  которые CSS ждёт снаружи;
- прогресс/проценты в дашбордах.

Правило применяется **к диффу**. В коде ~4 400 инлайн-стилей; массовая зачистка
не входит в задачу этого скилла и не должна попадать в отчёт.

---

## UI-040 — колонки detail-страницы

Должно быть `<div class="detail-grid">` / `detail-grid__col`.

**Нарушение:** `<Flex>` для раскладки колонок; `style="display: grid; grid-template-columns: ..."`.

**Не нарушение:** `<Flex>` для строки кнопок или мелких инлайн-элементов — это
не колонки страницы.

---

## UI-041 — CardAnimated   **[авто, частично]**

Thaw `<Card>` на detail-странице → должно быть `<CardAnimated delay_ms=N>`.
Проверь заодно шахматный stagger 0/40/80/120 у соседних карточек.

---

## UI-042 — модалки

`ModalFrame` + `ModalStackService` (ADR-0004).

**Нарушение:** свои `<div class="modal-overlay">` / `modal-content`; прямой
Thaw `<Dialog>` для нового окна.

---

## UI-050 / UI-053 — способ таблицы

Санкционированы два: Thaw `<Table>`; сырой `<table class="table__data">`
(для липкой первой колонки / матриц — `.data-matrix`).

**Нарушение:** новое семейство `.<что-то>-table` со своим набором
`width/border-collapse/thead th/tbody td/hover` — это ровно то, что
схлопывали. Такая таблица должна нести `class="table__data <page>-table"`,
а в page-CSS остаётся только реально отличающееся (ширины, плотность, шрифт).

**Образец:** `.data-matrix` в `components.css` — общая база + модификаторы
страниц (`roles-matrix`, `skills-matrix`, GL-матрица).

**Не нарушение:** `.data-table__*` в `shared/drilldown_report/` — второе
BEM-семейство с трёхуровневой шапкой и sticky; известное исключение, решается
вместе с `<StandardTable>`.

---

## UI-051 — одна обёртка прокрутки

Только `.table-wrapper`. Вложенность `.table-wrapper > .table-container`
или `.list-container > .table-container` — антипаттерн (составные правила
удалены 2026-08-14).

---

## UI-052 — шапка по левому краю

`.table__header-cell--right` не применять (CSS закомментирован в
`components.css`, класс инертен). Числа выравниваются по значению:
`.table__cell--right`.
