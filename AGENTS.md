# Repository instructions

- Не запускайте `cargo fmt` ради небольшой локальной правки: rustfmt форматирует файл целиком и может создать несвязанный diff. Форматируйте только затронутый фрагмент вручную, используйте `cargo fmt --check` для проверки и всегда просматривайте итоговый `git diff`.
- Перед созданием или переименованием архитектурного среза, роли либо индексированного каталога прочитайте `architecture.toml` в корне репозитория: это машинно-читаемый стандарт структуры проекта.
- После изменений архитектурной структуры обязательно запустите `powershell -NoProfile -File tools/check_architecture.ps1` и устраните нарушения либо оформите обоснованное исключение по правилам из `architecture.toml`.
