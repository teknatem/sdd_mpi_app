# WB Analytics API — выгрузка детальной истории воронки

Способ получить воронку за период глубже недели. Обычный метод истории отдаёт около семи дней
(см. `app__wb-api-funnel-history`); здесь WB готовит файл асинхронно, и глубина ограничена уже
не окном, а годом.

Механика из трёх шагов: заказать отчёт → дождаться готовности → скачать архив.

## Назначение и владелец

`create_sales_funnel_detail_report`, `get_sales_funnel_detail_report_status`,
`download_sales_funnel_detail_report` в импортном клиенте WB. Наполняют a036 за длинный период.

## Эндпоинты

**`POST https://seller-analytics-api.wildberries.ru/api/v2/nm-report/downloads`** — заказ
отчёта. Тело: собственный идентификатор запроса, тип `DETAIL_HISTORY_REPORT`, имя отчёта и
параметры — период, часовой пояс `Europe/Moscow`, `aggregationLevel: "day"`, пустые фильтры по
товарам, предметам, брендам и тегам (то есть весь каталог).

**`GET .../api/v2/nm-report/downloads?filter[downloadIds]=<id>`** — статус: `SUCCESS`,
`FAILED` или промежуточный.

**`GET .../api/v2/nm-report/downloads/file/{download_id}`** — файл. Заголовок
`Accept: application/zip`, таймаут 300 с. Внутри архива CSV; состав колонок проверяется, пустой
архив считается ошибкой.

## Лимиты и поведение

Опрос статуса — раз в 21 с, до 120 попыток, то есть **до 42 минут ожидания**. Период длиннее
года отклоняется до отправки запроса. Возвращённые в статусе границы периода сверяются с
запрошенными — WB иногда готовит отчёт не за то, что просили.

## Глубина истории

До года за одну выгрузку. Это единственный способ получить воронку глубже недельного окна.

## Цепочка потребителей

Три эндпоинта → **a036** (замещающая загрузка за период) → **p916**. Дальше — как у обычной
истории воронки.

## Расписание

В расписании нет: запускается вручную из импорта WB, целью «история воронки».

## ⚠️ Расхождения

**Нужна подписка «Джем».**
- *Официально*: метод описан в разделе аналитики.
- *На практике*: без подписки недоступен.
- *В коде сейчас*: требование отражено в подсказке интерфейса; отдельной обработки отказа по
  подписке для этого метода нет — в отличие от поисковой аналитики, где 403 обрабатывается
  мягко (см. `app__wb-api-search-analytics`).
- Статус: **подтверждено**.

**Отчёт может приехать не за тот период.**
- *Официально*: границы периода задаются в запросе.
- *На практике*: в готовом отчёте они иногда отличаются.
- *В коде сейчас*: границы сверяются с запрошенными после получения статуса.
- Статус: **подтверждено**.

**42 минуты ожидания — это верхняя граница, а не оценка.** Отчёт по большому каталогу
готовится долго, и запуск, упёршийся в лимит попыток, не означает отказ WB.
