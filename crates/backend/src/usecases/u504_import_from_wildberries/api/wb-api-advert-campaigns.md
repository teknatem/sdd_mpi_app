# WB Advert API — каталог рекламных кампаний

Справочник кампаний: какие кампании есть, какого типа, в каком статусе. Нужен как вход для
статистики (см. `app__wb-api-advert-fullstats`) — без списка идентификаторов запрашивать
расходы не по чему.

## Назначение и владелец

`fetch_advert_campaign_summaries` и `fetch_advert_campaign_info_values` в импортном клиенте WB.
Наполняют агрегат a030.

## Эндпоинты

**`GET https://advert-api.wildberries.ru/adv/v1/promotion/count`** — список кампаний с типом,
статусом и временем последнего изменения. Параметров нет.

**`GET https://advert-api.wildberries.ru/api/advert/v2/adverts?ids=<через запятую>`** —
подробное описание кампаний. Ответ приходит в трёх формах (объект со списком, голый массив,
одиночный объект) — разбор терпит все три.

## Лимиты и поведение

Официально для `promotion/count` и `api/advert/v2/adverts`: **5 запросов/с**, интервал 200 мс,
burst 5. Код использует более осторожный последовательный интервал 250 мс:

- за один запуск загружаются все новые/изменённые кампании пачками максимум по 50 ID;
- кампании, у которых не изменилось время правки и уже есть описание, пропускаются;
- при 429 ранее полученное описание сохраняется, а не затирается пустым;
- между вызовами выдерживается минимальный интервал 250 мс.

При 429 учитываются `Retry-After`/`X-Ratelimit-*`, число повторов ограничено.

## Глубина истории

Каталог отражает текущее состояние. Завершённые кампании остаются в списке, но их описание
может перестать отдаваться.

## Цепочка потребителей

Эндпоинты → **a030** (рекламная кампания WB) → используется как справочник кампаний для
загрузки статистики в a026. Собственных проекций и проводок у a030 нет.

## Расписание

`task012_wb_advert_campaigns`, cron `0 30 5 * * *` (UTC) = 08:30 МСК, ежедневно. Задача
`task011_wb_advert` перед загрузкой статистики обновляет список кампаний сама.

## ⚠️ Расхождения

**Наблюдаемое поведение:** отдельная пачка может получить 429 даже при соблюдении интервала.
Это не должно стирать ранее сохранённый `info_json`; остальные пачки текущего запуска
продолжают обрабатываться.
