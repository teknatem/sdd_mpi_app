# Финансовые метрики и сверка

Справочник для навыка `finance-analytics` / персоны «Финансист». Опирается на
бухгалтерскую модель (главная книга) и её DataView. Подробности GL — в знании
`general-ledger`; сверка YM — в знании `domain-a034_ym_realization`.

## Где данные

- **Обороты главной книги** — `dv004_general_ledger_turnovers` (`amount`, `entry_count`
  по turnover_code/формуле/слою). Таблица — `sys_general_ledger`.
- **Итог по счёту (account view)** — `dv005_gl_account_view_total` (balance/debit/credit).
- **Процентный KPI по оборотам** — `dv007_gl_turnover_ratio_percent`.
- **Взаиморасчёты YM** — `p907_ym_payment_report`; **сверка расчётов** — `a035_ym_settlement_recon`.
- **Официальная реализация YM** — `a034_ym_realization`.

## Слои учёта (`layer` в GL)

Поверх GL — параллельные слои оборотов:
- **fina** — оперативный слой (зеркало `p914`), источник `p907`; для YM покрывает
  **весь бизнес** (businessId: FBS+FBY).
- **ybuh** — официальный слой из отчётов о реализации (`a034`); тянется **по кампании**.
- **fact / oper / plan** — прочие слои. Сверку веди **в одном слое**; расхождение между
  слоями — это и есть предмет анализа.

## Сверка выручки YM (fina ↔ ybuh)

- **Ключ сопоставления**: заказ `order_id` (p907) = `order_id` строк a034; модель —
  `p907.model` = `a034.header.placement_type` (FBS/FBY).
- **Норма** (двусторонний дневной шум): разная дата признания — fina по дате доставки,
  a034 клампит дату к месяцу отчёта. По дням «плавает» ±, за месяц сходится.
- **Дефект** (стабильный односторонний перекос) = **разный охват**: fina покрывает все
  модели, ybuh — только импортированные кампании. Признак: перекос почти каждый день, в
  ₽ и шт, всегда в одну сторону. Лечение — переимпорт отчёта о реализации (`u503`,
  fan-out по всем кампаниям). См. `ym-recon-fina-ybuh-scope-mismatch`.

## Работа с GL

Перед SQL к `sys_general_ledger` — `list_gl_turnovers` (точные `turnover_code`), при
необходимости `get_chart_of_accounts` (план счетов: 7609/76YA/9001/9002 и т.д.).
Обороты — через `dv004`, не собирать CASE-суммы вручную.
