# WB Documents API — документы кабинета

Документы, которые WB формирует по кабинету: акты, отчёты, справки. Нужны для сверки с
финансовым отчётом и как первичка.

## Назначение и владелец

`fetch_documents_list` и `download_document` в импортном клиенте WB. Наполняют агрегат a027,
у которого есть отдельное извлечение содержимого из PDF.

## Эндпоинты

**`GET https://documents-api.wildberries.ru/api/v1/documents/list`** — список. Параметры:
`locale=ru`, `beginTime`, `endTime`, сортировка по дате по убыванию, `limit=50`, `offset`.

**`GET https://documents-api.wildberries.ru/api/v1/documents/download`** — скачивание.
Параметры: имя сервиса и расширение файла.

## Лимиты и поведение

Наблюдаемый лимит — **примерно 1 запрос в 10 секунд** с небольшим запасом на всплеск. Отсюда
пауза 11 с между страницами и до 3 повторов на страницу; при 429 читается заголовок с
рекомендованным ожиданием, по умолчанию 15 с.

Если WB просит ждать дольше 300 с, квота считается исчерпанной: запуск завершается особым
маркером, и задача переносится на сутки. Долбить исчерпанную квоту бесполезно.

## Глубина истории

Задаётся периодом, но фильтрация выполняется локально (см. расхождения). Обход прекращается,
как только встретился документ старше начала периода — сортировка по убыванию это позволяет.
Дата создания приходит в двух форматах — только дата или полная метка времени.

## Цепочка потребителей

Эндпоинты → **a027** (документы WB), включая извлечение данных из PDF. Проекций нет.

## Расписание

`task010_wb_documents`, cron `0 0 5 * * *` (UTC) = 08:00 МСК, ежедневно.

## ⚠️ Расхождения

**Параметры периода не фильтруют выдачу.**
- *Официально*: `beginTime` и `endTime` описаны как границы отбора.
- *На практике*: не гарантируют фильтрацию — в ответе приходят документы вне периода.
- *В коде сейчас*: сортировка по убыванию даты плюс отбор и ранний выход на нашей стороне.
- Статус: **подтверждено**.

**Лимит нигде не объявлен числом.**
- *Официально*: ограничение по частоте не документировано.
- *На практике*: около 1 запроса в 10 секунд, всплеск до пяти.
- *В коде сейчас*: пауза 11 с и обработка исчерпания квоты с переносом на сутки.
- Статус: **подтверждено** (значение получено опытным путём и может измениться).
