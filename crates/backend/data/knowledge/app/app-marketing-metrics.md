# Маркетинговые метрики маркетплейсов

Справочник определений для навыка `marketing-analytics` / персоны «Маркетолог».
Числа берём из семантического слоя (DataView), формулы — отсюда.

## Где данные

- **Рекламные расходы** — `dv002_wb_advert_by_items` (метрика `advertising_expenses`),
  источник `p911_wb_advert_by_items`.
- **Дневная статистика кампаний** (показы, клики, заказы с рекламы) — `a026_wb_advert_daily`;
  сами кампании — `a030_wb_advert_campaign`.
- **Воронка продаж** — `dv008_wb_sales_funnel` (источник `a036_wb_sales_funnel_daily`).
- **Поисковая аналитика / «Джем»** (видимость `visibility` %, позиции, запросы) —
  `a040_wb_search_analytics_daily`. Не источник показов (`impressions`=0) и не питает воронку.
- **Промо/акции** — `a020_wb_promotion`.
- **Выручка** (знаменатель для ДРР) — `dv001_revenue`.

## Определения

- **ДРР** (доля рекламных расходов, %) = рекламные расходы ÷ выручка × 100.
  Расход — `dv002.advertising_expenses`, выручка — `dv001.revenue` за тот же период и
  кабинет. Чем ниже — тем эффективнее реклама. Сравнивать fina/выручку и расход нужно
  строго по одному разрезу (период × кабинет).
- **CTR** (кликабельность, %) = клики ÷ показы × 100.
- **CPC** = расходы ÷ клики (цена клика). **CPO** = расходы ÷ заказы с рекламы.
- **Конверсии воронки** (уже посчитаны в dv008, не считать вручную):
  `cart_conv_pct` = корзины ÷ показы; `order_conv_pct` = заказы ÷ корзины;
  `buyout_pct` = выкупы ÷ заказы.
- **Выкуп (buyout)** — доля фактически выкупленных заказов (заказ ≠ выкуп: часть
  возвращается/не выкупается). Источник — воронка dv008 (`buyout_count`, `buyout_sum`).

## Метрики воронки dv008

`open_count` (показы карточки), `cart_count` (в корзину), `order_count`/`order_sum`
(заказы, шт/₽), `buyout_count`/`buyout_sum` (выкуп, шт/₽), `cart_conv_pct`,
`order_conv_pct`, `buyout_pct`. Группировки: `nm_id`, `date`, `connection_mp_ref`.

## Типичные вопросы

- «Какой ДРР за месяц?» → расход dv002 + выручка dv001 за период, поделить.
- «Где проседает воронка?» → dv008 drilldown по `nm_id`, смотреть на самую низкую
  из конверсий (`cart_conv_pct` / `order_conv_pct` / `buyout_pct`).
- «Эффективность кампании» → CPO/CPC из a026 против выручки/заказов.
